LEGACY AUTHORING EXPORT — NO LONGER REQUIRED IN THE MODPACK

From CyberNpc 0.45.7 onward the original Photon effect:
  cyberserver:summoning
is already bundled in CyberNpc.jar on every Minecraft client.

Do not install this separate ZIP when using CyberNpc 0.45.7+.
Photon for Forge 1.20.1 remains required.
CyberServer.jar itself remains server-side only.
This folder is retained only for backwards-compatible manual FX editing/export.
